AI-Based Sentiment Analyzer

Project Overview

This project is an AI-powered Sentiment Analyzer developed using Python and Hugging Face Transformers. The system analyzes user reviews and classifies them as Positive or Negative with a confidence score.

Features

- Sentiment Analysis using NLP
- User Review Classification
- Confidence Score Prediction
- Multiple Review Analysis
- Data Visualization using Pie Charts
- CSV Export Functionality

Technologies Used

- Python
- Transformers (Hugging Face)
- PyTorch
- Pandas
- Matplotlib

Project Workflow

1. Install required libraries
2. Load pre-trained sentiment analysis model
3. Analyze user reviews
4. Generate sentiment predictions
5. Visualize sentiment distribution
6. Export results to CSV

Sample Output

Review| Sentiment
I love this product| Positive
Worst purchase ever| Negative
